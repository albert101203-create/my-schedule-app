# 나의 주간 스케줄

월요일부터 일요일까지 한 주의 일정을 시간별 표로 확인하는 개인 일정 PWA입니다. 빈 시간 칸을 눌러 시작·종료 시간과 일정을 등록할 수 있습니다. 일정은 사용 중인 기기의 브라우저에 저장됩니다.

## 사용 방법

1. `index.html`을 브라우저로 엽니다.
2. 휴대폰에서 쓰려면 이 폴더를 정적 웹 호스팅(GitHub Pages, Netlify 등)에 올린 뒤, 브라우저 메뉴의 **홈 화면에 추가**를 누르세요.

> PWA 설치와 오프라인 사용은 HTTPS 웹 주소(또는 localhost)에서 동작합니다.
